# باسم محمد عبد الجابر | أتمتة الأعمال والذكاء الاصطناعي

صفحة هبوط عربية باتجاه RTL تعرض شهادات العملاء، نظاماً منجزاً، معرض فيديو، ودعوة لحجز جلسة تشغيلية عبر واتساب.

## التشغيل محلياً

```sh
npm install
npm run dev
```

لإنشاء نسخة الإنتاج والتحقق من الأنواع:

```sh
npm run build
npm run lint
```

## قبل النشر

- رابط واتساب ورقم الاتصال في `src/App.tsx` يستخدمان الرقم `+966580598411`.
- روابط Facebook وInstagram وYouTube تشير إلى حسابات صاحب الموقع.
- فيديوهات المعرض المضمنة هي `my assisant.mp4` و`the last news about ai and it.mp4`، ويقوم Vite بتضمينهما في نسخة الإنتاج.
- الشهادات وأسماء الشركات الواردة نصوص مقدمة من صاحب الموقع، فتحقق من الإذن باستخدامها قبل النشر.

## التقنيات

React وTypeScript وVite، مع Three.js عبر React Three Fiber للمشهد الهندسي ثلاثي الأبعاد.
